Alex — Python Voice Assistant

Desktop voice assistant

An experimental command-based voice assistant built in Python. Uses speech recognition and text-to-speech for practical desktop commands.

View source on GitHub

What the project covers

  • Voice commands
  • Time & web search
  • Wikipedia summaries
  • Notes and reminders

Run the original project locally

python -m pip install -r requirements.txt
python assistance.py
Deployment scope: The assistant needs a local microphone and Python process. This Vercel page is a project showcase, not a remote voice assistant.
